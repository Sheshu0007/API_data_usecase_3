# API to PostgreSQL Data Pipeline

## Description

Built a simple ETL pipeline using Python and PostgreSQL.

* Extracted product and customer data from public APIs.
* Transformed API JSON data using Python.
* Loaded the data into PostgreSQL.
* Created SQL queries for business reports using JOINs, aggregations, CTEs, and window functions.

## Technologies

* Python
* PostgreSQL
* SQL
* Requests
* Psycopg2

## Run

```bash
pip install -r requirements.txt
python main.py
```
